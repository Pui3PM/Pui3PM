# Mandatory 3PM Analyzer project rules — every AI / developer

These are explicit user requirements. Read this file, PROJECT_STATE.md and docs/QA_CURRENT.md before changing code. Apply to the entire tree and every future handoff/release.

1. **One public launcher, fixed name: `START_3PM.command`.** Every Mac release has exactly one `.command` file in the entire distribution. Never create launcher aliases, versioned launcher names, duplicate launchers or extra desktop shortcuts. AI/model/version changes do not change this filename.
2. Supporting shell scripts live under `internal/` as non-executable `.sh` files called through `/bin/bash`. Required frozen native executables live under `app/`; they are internal dependencies, not user launch choices.
3. Remove obsolete/contradictory READMEs, previous-build launchers, superseded QA documents, scratch outputs, logs, caches, temporary files, backups and unrelated project files from NEW distributions. Do not delete the user's sessions, DB, traces, uploaded originals or old installed folders. Build a fresh standalone package.
4. **Cleanup must preserve operation AND future development.** Keep runtime source, Swift helper sources/plists, models/assets/offline dependencies, licenses/attributions, meaningful tests/fixtures, current QA, project state and handoff instructions. Do not call an unreferenced runtime-generated endpoint/template unused without checking its producer and consumer.
5. `PACKAGE_CONTRACT.json` defines the root layout. Update the current SHA256SUMS manifest explicitly for reviewed changes; it must match all distributed files. Do not change the public launcher rule to make a failing package pass.
6. Before delivery run all `app/tests/test*.js`, `app/tests/stress*.js`, `app/tests/static_integrity_x282.py` and `app/tests/test_distribution_contract_r6.py`. Execute actual preflight via `app/tests/test_mac_preflight_r5.js`. Check paths with spaces, both runtime hashes, source/assets, executable bits and ZIP members. A contract failure blocks delivery until repaired. Test version/path expectations may follow intentional metadata/layout changes; behavioral assertions must not be weakened to hide regressions.

This exception does NOT authorize release/phase/scheduler/input-selection algorithm changes. Artifact-class policy (R8 P1-07, owner decision D-B option 1): `PACKAGE_CONTRACT.json` `artifact_class=development_not_release` ships the approved seam; `field_test_not_production` ships the frozen HV3 `pose.js` byte-for-byte (produced only by `app/tests/phase01/strip_pose_trace_seam.cjs`). Existing older fixture filenames are legacy labels, not independent equipment verification. Preserve provenance and never overwrite original fixtures merely to relabel their truth.
